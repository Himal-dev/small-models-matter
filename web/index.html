How to read this network
  • Every circle is one neuron. Its colour shows how active it is for the selected input: bright green is a strong positive activation, gray means it is switched off.
  • Every line is a weight. Green is positive, red is negative; thicker and brighter means a larger magnitude. To keep the picture readable, only the two strongest incoming weights per neuron are drawn in the background by default. Turn on All 19,840 connections for the dense view. Click a hidden or output neuron to see its full equation and highlight its connections.
  • The white ring marks the neuron you are inspecting. Click a circle or use the Inspect control above to change it. Its incoming and outgoing weights are highlighted. The yellow outline on an output neuron is the action the agent chose.
  • A hidden neuron computes z = Σ wixi + b, then a = max(0, z) (ReLU). The bias b shifts the result; the weights w decide which inputs matter.
  • The three output circles are Q-values: the network's estimate of future reward for going straight, turning right, or turning left. The agent picks the largest one.
  • Once the replay buffer has enough samples, Adam takes one optimizer step per game step. The watcher reads checkpoints saved once per episode.
  • The Learning Story panel at the bottom explains what the weights are being changed for: the reward, the Bellman target, the loss, and the update. The demo TD error illustrates the calculation without updating the model.
  • The auto demo board is a separate game played by the latest checkpoint. It is there so you can watch the network respond to a changing state; it is not the trainer's pygame window.

THE LEARNING STORY

why the weights move, and what they move toward

1 · THE GOAL

The snake should survive and eat food. The score is the real objective, but you cannot run backpropagation through “score”. So every move pays a reward, and the network learns to predict the discounted future reward of each action.

2 · THE TARGET

Each transition (s, a, r, s') becomes a target with the Bellman equation. This is the number the network is asked to match: 

target = r + γ · max Qtarget(s', a')
γ = 0.90

If the game ended there is no future, so target = r.

3 · THE LOSS

The network predicts Q(s, a) for the action it took. The loss is the squared gap between that prediction and the target, averaged over a random batch of past moves: 

L = (1/N) Σ ( Q(s,a) − target )²
N = 128

The gap between Q(s,a) and the target is the TD error. Its effect on each parameter depends on the gradients through the network and the other samples in the batch.

4 · THE UPDATE

Backpropagation computes ∂L/∂w for all 20,099 parameters. A simple gradient step would be: 

w ← w − lr · ∂L/∂w
lr = 0.001

The trainer clips the gradient norm to 1.0 and uses Adam, which scales the update using running estimates of the gradients.

γ sets how far ahead the agent looks. Replay memory breaks the correlation between consecutive moves. The target network is a frozen copy, refreshed every 200 updates, so the target stops chasing itself.

THE PROXY · LOSS OVER EPISODES

Mean squared TD error. The target moves as the network changes, so this can rise while the snake improves. Treat it as a stability signal, not the goal.

THE REAL GOAL · SCORE OVER EPISODES

Episode score and running average. This is what we actually care about.
